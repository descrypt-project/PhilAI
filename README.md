# PhilAI 2027

Website for **PhilAI 2027**, a workshop on **Philology, Artificial Intelligence, and Rare Scripts**, to be held in Stockholm, Sweden.

The website contains information about the workshop programme, important dates, submissions, instructions, organisation, and venue.

## Local preview

The website consists of static HTML and CSS files and can be previewed locally without any additional dependencies beyond Python.

Clone the repository:

```bash
git clone https://github.com/WoutSin/philai-2027.git
cd philai-2027
python3 -m http.server 8000
